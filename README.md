# SUMA

Aplicación móvil de ahorro consciente: registra el dinero que decides **no gastar** y muestra el progreso acumulado.

> El importe registrado es una estimación declarada por el usuario. No implica que el dinero esté apartado ni que el patrimonio haya aumentado.
